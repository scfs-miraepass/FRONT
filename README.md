# MIRAE PASS FRONT
---
미래 패스 서비스의 프론트 시스템

## 🔒 개발 환경설정
---
```bash
# Git clone
git clone https://git.rldn.xyz/scfs.miraepass/front.git
cd front

# 필요 라이브러리 설치및 환경 구성
yarn install

# 환경변수 설정
cp example.env .env
vi .env

# 개발 환경 실행
yarn dev
```
